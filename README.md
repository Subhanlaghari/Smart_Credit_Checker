# 🩺 AI Disease Prediction System

An AI-powered Disease Prediction Web Application developed using Python, Machine Learning, and Streamlit.

## 🚀 Features

- 🩺 Disease Prediction using Symptoms
- 📖 Disease Information
- 💊 Precautions
- 🥗 Recommended Diet
- 👨‍⚕️ Recommended Specialist
- 📊 Prediction Confidence
- 🎨 Beautiful User Interface

## 🛠 Technologies Used

- Python
- Streamlit
- Scikit-learn
- NumPy
- Joblib
